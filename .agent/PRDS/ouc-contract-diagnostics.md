# 教务 Provider：OUC 页面契约失败留样

**Priority:** High
**Status:** In Progress
**Type:** Enhancement
**Created:** 2026-08-25
**Last Updated:** 2026-08-25

## 概述

学校教务页面可能返回 HTTP 200，但页面结构变化会使 Provider 解析失败并返回 `contract_changed`。为支持复现和修复，Provider 默认保存所有解析失败对应的完整原始响应。

## 要求

- 默认开启；覆盖课程、成绩、考试、选课、学期和课程目录的页面/JSON 解析失败。
- 文件仅保存在 Provider 宿主机受限挂载目录，不经 API、Redis、数据库、Prometheus 或容器标准日志传输。
- 每个样本完整保留响应正文；文件名不携带学号、姓名、Cookie、查询参数或业务数据。
- 日志仅记录样本 ID、SHA-256、字节数、操作、教育层级、host、path、解析阶段与失败类别。
- 每次写入前清理超过 48 小时的样本；保留期固定为 2 天。
- 留样写入或清理失败不得改变原有客户端错误语义。

## 实现范围

- 增加 Provider 诊断留样组件与单元测试。
- 在通用查询解析、JSON 校验、课程目录解析和异常响应位置接入。
- 增加 Provider 运行配置和 Docker 宿主机挂载目录，默认启用持久化留样。
- 补充运维文档：样本定位、权限边界、两天清理和人工复现流程。

## 安全边界

- 原文可能包含学生身份、课程和成绩信息；目录权限为仅运行账户可读写，文件权限为 `0600`。
- 不记录正文、Cookie、请求头、学号或密码到日志。
- 留样只用于运维修复；两天后自动删除，人工读取后不得外传。

## 验收

- 解析失败产生完整 `.html` 或 `.json` 样本，并记录安全诊断摘要。
- 48 小时前样本会被清理；新样本不会被误删。
- 默认配置包含持久化宿主机挂载，不需要额外开关。
- 写入失败不掩盖原本的 `contract_changed` 或其他 Provider 错误。
